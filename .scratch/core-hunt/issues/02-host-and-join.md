# 02: Hospedar e Entrar

**What to build:** dois jogadores em máquinas diferentes se veem andando na
mesma Arena. Quem clicou em Hospedar roda a Simulação e é a verdade final;
quem clicou em Entrar só manda o que está apertando e desenha o que recebe.

**Blocked by:** 01

**Status:** done

- [x] Até 4 Caçadores na mesma Arena
- [x] Só o Anfitrião roda a `Sim`
- [x] O Cliente manda apenas Entrada e recebe apenas Instantâneo
